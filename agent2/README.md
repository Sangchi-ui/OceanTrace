# OceanTrace — Agent 2: Physics-Based Hindcasting & Forecasting

Agent 2 is the trajectory, hindcasting, and forecasting intelligence component of the OceanTrace maritime oil spill attribution platform. It consumes georeferenced oil slick detections generated by **Agent 1 (Sentinel-1 SAR Detection)** and answers two foundational environmental questions:

1. **Hindcasting**: *"Where did this detected oil spill probably originate, and during what time window?"*
2. **Forecasting**: *"Where will the detected oil spread and drift next (+6h, +12h, +24h)?"*

## 2. Scientific & Engineering Principles

* **Physics First, ML Second**: Drift advection and spreading are driven by physical oceanography (4th-order Runge-Kutta Lagrangian particle dynamics, ocean currents, atmospheric windage, and stochastic eddy diffusion), not black-box neural networks learning physics from scratch.
* **Two-Stage Hindcasting (No Naive Reverse Physics)**: Reversing stochastic diffusion equations backward in time is mathematically ill-posed. Agent 2 uses **Stage A (Backward Search Envelope)** to establish plausible corridors, followed by **Stage B (Forward Replay of Candidate Origins)** with multi-metric scoring.
* **Regions and Time Windows (No False Precision)**: Agent 2 never outputs a single falsely precise point coordinate when data uncertainty cannot justify one. Output origins are geographic regions with confidence intervals.
* **Strict No-Fabrication Policy**: Missing environmental datasets are never silently fabricated. Un-georeferenced imagery raises explicit errors rather than inventing false coordinates.

## 3. Mathematical Transport Model

The Lagrangian particle position $\vec{x} = (\lambda, \phi)$ evolves according to:

$$\frac{d\vec{x}}{dt} = \vec{u}_{\text{current}}(\vec{x}, t) + \alpha_{\text{wind}}\,\vec{u}_{10}(\vec{x}, t) + \vec{u}_{\text{diff}}$$

Where:
* $\vec{u}_{\text{current}}$ is the ocean surface velocity vector ($u, v$) in m/s.
* $\vec{u}_{10}$ is the 10-meter atmospheric wind velocity vector in m/s.
* $\alpha_{\text{wind}}$ is the windage leeway coefficient (configurable, literature baseline 2.5%–4.4%, default 3.0%).
* $\vec{u}_{\text{diff}} = \sqrt{\frac{2 D_h}{\Delta t}}\,\vec{\mathcal{N}}(0, 1)$ is the stochastic horizontal turbulent eddy diffusion ($D_h \approx 2.5\,\text{m}^2/\text{s}$).

Integration is executed using **4th-Order Runge-Kutta (RK4)** with geodesic metric conversions:

$$d\phi = \frac{v \cdot \Delta t}{R_{\text{earth}}}, \quad d\lambda = \frac{u \cdot \Delta t}{R_{\text{earth}} \cos\phi}$$

## 4. Source Hypothesis Scoring

Candidate origins tested during Stage B forward replay are evaluated against the observed Agent 1 slick using a modular composite metric:

$$S_{\text{total}} = w_c S_{\text{centroid}} + w_{\text{iou}} S_{\text{iou}} + w_a S_{\text{area}} + w_s S_{\text{shape}}$$

* **Centroid Distance Score**: $S_{\text{centroid}} = \exp\left(-\frac{d^2}{2\sigma^2}\right)$ with $\sigma = 3.5\text{ km}$.
* **Spatial Overlap Score**: $S_{\text{iou}} = \frac{\text{Area}(\text{Observed} \cap \text{Simulated})}{\text{Area}(\text{Observed} \cup \text{Simulated})}$.
* **Area Ratio Score**: $S_{\text{area}} = \frac{\min(A_{\text{sim}}, A_{\text{obs}})}{\max(A_{\text{sim}}, A_{\text{obs}})}$.
* **Shape Similarity Score**: $S_{\text{shape}} = 1 - \frac{|AR_{\text{sim}} - AR_{\text{obs}}|}{\max(AR_{\text{sim}}, AR_{\text{obs}})}$.

Default weights in [configs/agent2.yaml](file:///d:/PROJECTS/OceanTrace/configs/agent2.yaml): $w_c = 0.35, w_{\text{iou}} = 0.35, w_a = 0.15, w_s = 0.15$.

## 5. Usage

### Command-Line Interface (CLI)

```bash
# Run both Hindcast and Forecast from an Agent 1 output
python -m agent2.cli \
    --input outputs/sample_spill_event.json \
    --output outputs/agent2_results \
    --mode both \
    --config configs/agent2.yaml

# Run Forecast only
python -m agent2.cli \
    --input outputs/sample_spill_event.json \
    --output outputs/forecast_only \
    --mode forecast
```

### Training the XGBoost Physics Residual Model

To train or fine-tune Agent 2's XGBoost models on drift trajectory / buoy tracking datasets:

```bash
# 1. Generate or prepare a trajectory dataset (CSV or Parquet)
python -m agent2.ml.generate_drift_dataset --samples 2500 --output data/drift_trajectories_sample.csv

# 2. Train XGBoost models on the dataset
python -m agent2.ml.train_xgboost \
    --data data/drift_trajectories_sample.csv \
    --output models/agent2 \
    --estimators 150 \
    --depth 5 \
    --lr 0.05
```

This trains and exports:
* `models/agent2/xgb_dx_residual.json` ($dx$ physical displacement residual model)
* `models/agent2/xgb_dy_residual.json` ($dy$ physical displacement residual model)
* `models/agent2/xgb_uncertainty.json` (dynamic uncertainty scaling model)
* `models/agent2/metrics.json` (validation MAE, RMSE, $R^2$ scores, and feature importances)

When `Agent2Pipeline` runs, it automatically loads these models from `models/agent2/`.

### Python API

```python
from agent2.adapters.agent1_adapter import Agent1Adapter
from agent2.pipeline import Agent2Pipeline

# Load and validate Agent 1 output
spill = Agent1Adapter.from_file("outputs/spill_event.json")

# Initialize and execute pipeline
pipeline = Agent2Pipeline(config_path="configs/agent2.yaml")
result = pipeline.run(spill, mode="both")

# Access Hindcast probable origin
if result.hindcast.enabled and result.hindcast.probable_origin:
    po = result.hindcast.probable_origin
    print(f"Origin Centroid: {po.centroid}")
    print(f"Time Window: {po.time_window_start} to {po.time_window_end}")
    print(f"Confidence: {po.confidence:.2%}")

# Access Forecast horizons
for horizon in result.forecast.horizons:
    print(f"+{horizon.horizon_hours}h: Drift {horizon.drift_distance_km} km, Area {horizon.spread_area_km2} km^2")

# Export all JSON and GeoJSON artifacts
pipeline.export_artifacts(result, output_dir="outputs/agent2_run")
```

### REST API

The FastAPI service exposes Agent 2 endpoints without modifying Agent 1:

```bash
# Start API server
uvicorn app.api.main:app --port 8000 --reload
```

* `GET  /api/v1/agent2/health`: Agent 2 status and physics engine metadata.
* `POST /api/v1/agent2/analyze?mode=both`: Accepts JSON payload of `SpillEvent` or `SpillObservation`.
* `POST /api/v1/agent2/analyze-file`: Accepts uploaded `spill_event.json` or `spill.geojson`.

## 6. Output Artifacts

Running Agent 2 exports:

* `agent2_result.json`: Comprehensive machine-readable output contract for Agent 3.
* `agent2_analysis.geojson`: Unified multi-layer GeoJSON FeatureCollection (Observed slick, Probable Origin Region, Best Candidate Path, Forecast 50% Core, Forecast 90% Outer Spread, and Forecast Centroids).
* `geojson/origin_region.geojson`: Dedicated Probable Origin Region polygon.
* `geojson/hindcast_paths.geojson`: Best historical candidate trajectory LineString.
* `geojson/forecast_6h.geojson`, `forecast_12h.geojson`, `forecast_24h.geojson`: Horizon-specific dispersion polygons.
